## Overview

### **光碟規格（Disc Format）**

- **Red Book CD**

編碼方式：PCM

位深：16-bit

取樣率：44.1kHz

特點：CD-DA 標準，兼容性高，可用任何 CD 播放器播放

- **SACD**

編碼方式：DSD（Direct Stream Digital）

位深：1-bit

取樣率：2.8224 MHz (DSD64)，部分為 5.6448 MHz (DSD128)

特點：高解析光碟，需 SACD 播放器或支援機種播放

- **Hybrid SACD**

編碼方式：CD 層（PCM 16/44.1）+ SACD 層（DSD64）

位深：16-bit / 1-bit

取樣率：44.1kHz（CD 層） / 2.8224 MHz（SACD 層）

特點：雙層光碟，普通 CD 播放器可播 CD 層，SACD 播放器可播高解析層（部分含多聲道）

- **MQA CD**

編碼方式：PCM 封裝 MQA

位深：16-bit（表層）

取樣率：44.1kHz（表層），經 MQA DAC 解碼／渲染後最高可達 352.8kHz

特點：兼容普通 CD 播放器，支援 MQA 的 DAC 可解碼展開

- **XRCD / K2HD CD**

編碼方式：PCM（優化製程）

位深：16-bit（光碟規格），母帶處理可達 24-bit

取樣率：44.1kHz（光碟規格），母帶升頻可至 192kHz+

特點：重點在母帶與壓片處理，與普通 CD 播放器完全兼容

### **音訊編碼方式（Audio Encoding）**

- **PCM (Pulse Code Modulation)**

編碼方式：PCM

位深：16 / 24 / 32-bit

取樣率：44.1kHz, 48kHz, 88.2kHz, 96kHz, 176.4kHz, 192kHz, 352.8kHz, 384kHz

特點：最常見的數位音訊格式，無壓縮或無損壓縮（WAV, FLAC, ALAC）

- **DSD (Direct Stream Digital)**

編碼方式：DSD

位深：1-bit

取樣率：DSD64 (2.8224 MHz), DSD128 (5.6448 MHz), DSD256 (11.2896 MHz), DSD512 (22.5792 MHz)

特點：高解析音質，常見於 SACD，檔案容量大，播放需求高

- **MQA (Master Quality Authenticated)**

編碼方式：PCM 封裝 MQA

位深：16-bit / 24-bit

取樣率：44.1kHz 或 48kHz（封裝），完整展開後可達 384kHz

特點：兼容性高，屬有損摺疊編碼，音質宣稱具爭議；Tidal 已於 2024 年停用
